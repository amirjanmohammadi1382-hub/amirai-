# AMIR AI

پروژهٔ مستقل AMIR AI؛ جدا از مخزن محمدی موبایل.

## قابلیت‌های افزوده‌شده
- محیط سه‌بعدی مبتنی بر Three.js با ۱۳ فضای مشاورهٔ اختصاصی، میز، نمایشگر، نورپردازی و مدل‌های انسانی هندسی با جزئیات بیشتر
- چرخش، زوم و انتخاب شخصیت با لمس/کلیک
- ۱۳ شخصیت تخصصی و کارت‌های انتخاب
- گفتار خروجی با Speech Synthesis مرورگر
- ورودی گفتار در مرورگرهایی که Web Speech Recognition را پشتیبانی می‌کنند
- اتصال اختیاری به Gemini API با مدل `gemini-3.1-flash-lite`؛ کلید توسط کاربر وارد و فقط در localStorage همان دستگاه ذخیره می‌شود
- ثبت پیش‌نویس درخواست‌ها و افزودن شخصیت سفارشی در حافظهٔ محلی
- PWA manifest و service worker

## فعال‌سازی هوش مصنوعی
1. در Google AI Studio یک API key رایگان بسازید: https://aistudio.google.com/app/apikey
2. برنامه را از HTTPS باز کنید.
3. «تنظیم اتصال هوش مصنوعی» را بزنید و کلید را وارد کنید.

کلید به GitHub فرستاده نمی‌شود، اما چون اتصال در مرورگر انجام می‌شود، برای برنامهٔ عمومی/چندکاربره این روش مناسب نیست. برای انتشار عمومی باید backend امن و ذخیرهٔ کلید به‌صورت secret راه‌اندازی شود. سهمیهٔ رایگان ممکن است محدود یا تغییر کند. در سطح رایگان، داده‌های ارسال‌شده ممکن است طبق شرایط Google برای بهبود محصولات استفاده شوند؛ اطلاعات حساس را وارد نکنید.

## محدودیت‌های فعلی
- شخصیت‌های سه‌بعدی فعلی مدل‌های انسانی هندسی و قابل‌تشخیص‌اند؛ هنوز چهره‌های فوتورئال/اسکن‌شده یا مدل‌های اختصاصی ساخته‌شده با ابزار حرفه‌ای نیستند.
- انیمیشن لب‌خوانی و حرکت چهرهٔ واقعی هنوز پیاده‌سازی نشده.
- صدای گفتار از صداهای موجود روی دستگاه انتخاب می‌شود؛ صدای یکتا برای هر شخصیت و دری افغانستانی در همهٔ گوشی‌ها تضمین نیست.
- تشخیص گفتار به پشتیبانی مرورگر و زبان وابسته است.
- حافظه، درخواست‌ها و شخصیت‌های سفارشی فعلاً محلی‌اند؛ همگام‌سازی ابری، همکاری واقعی شخصیت‌ها، گزارش خودکار و APK هنوز ساخته نشده‌اند.
- محیط سه‌بعدی و کتابخانه‌ها از CDN بارگیری می‌شوند و برای بار اول اینترنت لازم دارند.

## اجرا
میزبانی روی HTTPS لازم است تا PWA، میکروفون و برخی قابلیت‌های مرورگر به‌درستی کار کنند.
