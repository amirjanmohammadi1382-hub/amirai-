# AMIR AI

پروژهٔ مستقل AMIR AI؛ جدا از مخزن محمدی موبایل.

## اجرای نسخهٔ پایه
مخزن را روی GitHub Pages یا یک میزبان HTTPS نشر کنید و فایل `index.html` را باز کنید.

## وضعیت فعلی
- رابط واکنش‌گرا و راست‌به‌چپ
- ۱۳ کارت شخصیت تخصصی
- ثبت پیش‌نویس درخواست‌های تغییر در حافظهٔ محلی مرورگر
- افزودن شخصیت سفارشی در حافظهٔ محلی مرورگر
- manifest و service worker برای آماده‌سازی نصب PWA

## هنوز پیاده‌سازی نشده
هوش مصنوعی زنده، اتاق‌های سه‌بعدی، گفتار و همگام‌سازی ابری، همکاری واقعی شخصیت‌ها، گزارش‌های زمان‌بندی‌شده و بستهٔ APK. برای این موارد backend، سرویس‌های مربوط و تنظیم امن کلیدهای API لازم است. این نسخه ادعای اجرای این قابلیت‌ها را ندارد.
